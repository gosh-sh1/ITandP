FoodGo - адаптивный макет сервиса доставки еды

Лабораторная работа №6 по дисциплине «Информационные технологии и программирование» (тема: «Макетирование и адаптивность: Flexbox, Grid и Mobile First»).

Вариант 14, «Сервис доставки еды» - шапка с корзиной, сетка ресторанов, сайдбар с фильтрами.

Описание

Статический адаптивный макет главной страницы сервиса доставки еды (только HTML и CSS, без JavaScript). Разметка и стили станут основой для следующей лабораторной работы, где в интерфейс добавится интерактивность.

Возможности
Шапка с логотипом и кнопкой корзины со счётчиком.
Сайдбар с фильтрами (кухня, рейтинг, время доставки).
Сетка карточек ресторанов.
Подвал.
Используемые технологии и подходы
CSS Grid (grid-template-areas) - общий каркас страницы и сетка карточек.
Flexbox - шапка, фильтры, содержимое карточек.
Mobile First - базовые стили для мобильных, расширение через @media (min-width).
БЭМ - именование классов (restaurant-card__title, header__cart-count и т. д.).
Семантическая вёрстка: header, aside, main, article, footer.
